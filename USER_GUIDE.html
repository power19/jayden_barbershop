1. What this app does

This system is made up of two connected parts:

📱 WhatsApp Bot

Customers message the shop's WhatsApp number. The bot greets them, lets them pick a language, browse services, check hours/location, and book an appointment — all without installing an app.

🖥️ Admin Dashboard

A web page (open in any browser) where the shop owner/staff manage everything: appointments, barbers, working hours, services & prices, photos, customers, and all the bot's settings and messages.

Appointments booked through WhatsApp are automatically synced to Google Calendar, so the barber's schedule always stays up to date.

2. The customer experience (WhatsApp)

When someone messages the shop's WhatsApp number for the first time, the bot walks them through:

Customer sends any message │ ▼ 🌐 Choose a language (Dutch / English / Spanish / French / Portuguese) │ ▼ 📋 Main Menu ├─ Book an appointment → service → barber → date → time → name → confirm ✅ ├─ Services & prices ├─ Opening hours ├─ Location ├─ Photo gallery of haircuts ├─ Change language ├─ Manage my appointment (reschedule / cancel) └─ Call us

Returning customers who already picked a language and gave their name skip straight to the main menu and get a personal welcome.

Need to step in personally? Staff can "take over" a chat by sending the takeover keyword (configurable in Settings → Booking, default #human) — this pauses the bot for that customer so a real person can reply. Send the release keyword (default #bot) to hand the conversation back to the bot.

3. Logging into the admin dashboard

  1. Open the dashboard URL in a browser (the one configured under Settings → Integrations → Shop URL).
  2. Enter the admin password (set in Settings → Security; change it from the default as soon as possible).
  3. You'll land on the Dashboard page, showing today's schedule and key numbers at a glance.
Tip: Bookmark the dashboard on your phone's home screen — it works like a regular web page on mobile.

4. Dashboard walkthrough

The sidebar gives you access to every part of the shop. Here's what each section is for:

📊 Dashboard

A quick overview: today's appointments, upcoming bookings, and key shop numbers — your daily starting point.

📅 Appointments

See every booking — past, upcoming, no-shows, and rated visits. Filter, search, reschedule, cancel, mark as completed/no-show, and re-sync individual appointments (or all of them) to Google Calendar.

👥 Employees

Add and manage barbers: names, photos, which services they perform, and whether they're currently active or "away".

🕒 Work Hours

Set opening and closing times for each day of the week — per barber if needed. This controls which time slots the bot offers to customers.

✂️ Services

Manage the list of services offered (haircut, beard trim, etc.), their prices, durations, and whether they're currently bookable.

🏖️ Leave

Schedule time off for individual barbers (holidays, sick days). The bot automatically stops offering slots with that barber during their leave period.

🚫 Closed Dates & Blocks

Block off whole days or specific time windows shop-wide — public holidays, special closures, etc. Surinamese public holidays can be synced in automatically.

📸 Gallery

Upload and tag photos of haircuts/styles. Customers can browse this gallery from the WhatsApp main menu for inspiration.

📋 Menu Order

Control which options appear in the bot's main menu, their order, whether they're enabled, and their labels.

🎓 Training

Upload training videos for new barbers — accessible through the bot's "Barber course information" option.

👤 Customers

Browse the customer list — names, phone numbers, preferred language, booking history, and the option to block/unblock problem customers.

🔑 Keywords

Define custom keywords/phrases the bot should recognise and respond to outside the normal menu flow (e.g. FAQs, special triggers).

💬 Bot Messages

Customise the wording of automatic messages the bot sends (welcome messages, reminders, confirmations, etc.).

5. Daily / weekly routine

  • Each morning — open the Dashboard to see today's bookings and confirm staffing.
  • When a barber is off — add it under Leave so the bot stops offering them as an option.
  • Holidays / closures — add them under Closed Dates & Blocks ahead of time.
  • New haircut photos — upload to the Gallery regularly to keep it fresh for customers.
  • Check no-shows — review the Appointments page; repeat no-shows trigger the warning messages configured under Settings → Rules.

6. The barber check-in scanner

Each barber can use a dedicated check-in page (separate from the admin dashboard) to scan a customer's appointment QR code when they arrive. It's protected with its own PIN (set under Settings → Security), and only works within the configured check-in time window around the appointment time.

7. Troubleshooting

ProblemWhat to try
Bot isn't replying to customersCheck the WhatsApp connection status in the dashboard — the phone may have lost its link and need re-scanning.
A customer is stuck talking to the bot and needs a humanSend the takeover keyword (default #human) in that chat, reply manually, then send the release keyword (default #bot) when done.
No time slots are showing for bookingCheck Work Hours, Leave, and Closed Dates — one of these may be blocking availability. Also confirm the Google Calendar connection in Settings → Integrations.
Wrong shop info shown to customers (address, phone, etc.)Update it under Settings → Shop — changes apply immediately, no restart needed.
Forgot the admin passwordAsk whoever manages the server to reset it directly in the system settings.
